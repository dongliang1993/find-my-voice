name: finding-my-voice-setup
description: 初始化或继续 Finding My Voice，把共同经历整理、角色画像、Agent 自主选声、试听和声音确认串成一个流程。用户说“初始化 Finding My Voice”“帮我设置声音”或首次使用此插件时使用；普通文字交流不重复初始化。
---

这是 Finding My Voice 的统一入口。调用 `setup.start` 读取有效进度，从尚未完成的一步继续，不清空或重复建立已确认内容。若工具不可用，检查本地 MCP 是否已连接；不要用测试默认音色宣称初始化完成。

先说明当前进度与接下来的一步，不要求用户自己了解底层工具。`setup.start` 只返回引导，不会自动保存数据或生成付费语音。没有凭证时可以先整理记忆和角色，真实试听前再通过私有本机配置补齐；不要让用户在对话中贴 API Key。

1. **共同经历。** 使用同包 `identity-evolution`：根据当前实际可用对话或用户提供的材料提出有来源的记忆草稿，允许删改。调用 `memory.save` 准备具体变更，等用户通过宿主表单或本地管理页面确认，再读取实际记忆 ID。新安装时没有其他对话的历史；材料不足就请用户提供一小段交流，不编造关系经历。
2. **表达画像。** 由 Agent 从已确认记忆形成自己的表达原则、处理分歧的方式和不确定项，向用户解释依据。调用 `identity.update`，引用实际记忆 ID 和当前 `base_version`。待确认不是保存成功；用户确认后再继续。不要把画像改成对用户的人格分析。
3. **设计声音、试听。** 使用同包 `voice-expression`：先提出自己的声音设计、首选与理由，再调用 `voice.list` 核对目录，用相同短台词和可比较参数试听相关候选。选声主体是 Agent，用户提供听感反馈。试听是用户发起 setup 中的一部分；仅在用户接受试听及收费说明后调用真实 TTS，不因读取进度自动生成音频。
4. **确定声音。** Agent 吸收反馈，给出最终选择和理由。通过 `identity.update` 提交具体声音配置与当前版本，保留画像已有的记忆依据，用户确认后保存；不把临时试听覆盖或测试音色当作正式声音。再次调用 `setup.start`；只有工具返回 `ready: true` 才报告流程就绪。

拒绝某次草稿时留在该步骤修订，重用请求 ID 查询同一操作；内容修改才使用新 ID。中途离开后重新读取 `setup.start` 即可恢复，不根据旧对话断言已确认。版本冲突时读取新版本，重新提出差异。

本地 Mac 可使用 `playback: stream` 直接流式播放，`voice.control` 可查询或停止；其他宿主用 `playback: none` 生成文件或回放组件。不要在远程网页调用本地系统播放，也不保证网页自动播放。

结束时给出当前角色与声音、选择依据，以及“用声音回答我”“只用文字”“停止播放”的使用方式。持续自主语音需要用户明确开启；默认 explicit 模式不在普通文字交流中调用收费音频接口。
